# قسم الكتب الرقمية التفاعلية وجدولة عرض التفاصيل

خطة هندسية شاملة لبناء محرك تصفح الكتب الرقمية التفاعلية (Digital Book Reader) داخل مشغل الوسائط بناءً على خريطة البيانات وهيكل المجلدات والصورة المرفقة، مع ضبط وتنسيق جدول التفاصيل والأحجام والترتيب.

---

## مراجعة القرارات المؤكدة مع المستخدم (Confirmed Decisions)

> [!IMPORTANT]
> تم تأكيد خيارات المستخدم في مرحلة الاستفسار التفاعلية على النحو التالي:

- **آلية استيراد الكتب**: دعم رفع ملف **ZIP** أو مجلد محلي يحوي البيانات (`content.json` و `book.json`)، وصور الصفحات (`pages/`)، وملفات الوسائط (`audio/` و `video/`)، مع تضمين كتاب تجريبي تفاعلي جاهز مستوحى من عينة الصورة (`Miteinander! A1.1`).
- **موضع القسم**: تبويب مخصص ومنفصل بعنوان **"الكتب الرقمية"** بجوار تبويب **"مستعرض الوسائط"** داخل مساحة عمل المشغل.
- **آلية تشغيل الوسائط**: تشغيل المقاطع الصوتية والمرئية المرتبطة بصفحة الكتاب في **استوديو مشغل الوسائط المتقدم الحالي** مع إمكانية التشغيل السريع المدمج.
- **نمط تصفح الصفحات**: **عارض أفقي تفاعلي (Horizontal Carousel)** مطابق تماماً للصورة المرفقة: يعرض الصفحة السابقة، الصفحة النشطة في المنتصف مع رقمها، والصفحة اللاحقة، مع إمكانية التقليب السلس والتكبير.
- **تنسيق جدول التفاصيل**: إعادة ترتيب وتنسيق أعمدة جدول التفاصيل في مستعرض الوسائط (الاسم، النوع، الحجم، المدة، التاريخ، الإجراءات) بأبعاد ثابتة ومحاذاة بصرية منضبطة.

## 1. الفكرة العامة والهدف (Overview & Core Concept)

تمكين المستخدم من قراءة الكتب التعليمية الممسوحة ضوئياً وتصفح صفحاتها بجودة عالية، مع ربط كل صفحة تلقائياً بملفاتها الصوتية أو المرئية الخاصة بها فقط بمجرد الانتقال إليها، وتشغيل هذه المقاطع في استوديو الوسائط دون فقدان سياق القراءة.

```
┌────────────────────────────────────────────────────────────────────────┐
│                        Top Bar: Book Title & Search                    │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│          [ Prev Page ]     ┌────────────────────┐     [ Next Page ]    │
│            (p. 174)        │    Active Page     │        (p. 176)      │
│                            │      (p. 175)      │                      │
│                            └────────────────────┘                      │
│                                      175                               │
├────────────────────────────────────────────────────────────────────────┤
│ Page Media Tracks (Audio / Video Binding):                             │
│  ▶  2/36 – Audio: L7, 6a   [ Audio ]  [تشغيل في المشغل]               │
│  ▶  2/37 – Audio: L7, 6b   [ Audio ]  [تشغيل في المشغل]               │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. تجربة المستخدم والتصميم البصري (UX & Visual Design)

### أ. تدفق تجربة المستخدم (User Flows)
1. **الوصول إلى قسم الكتب**:
   - داخل مساحة عمل الوسائط، يظهر شريط تبويبات علوي نظيف: `[ ملفات الوسائط ]` و `[ الكتب الرقمية ]`.
   - عند اختيار "الكتب الرقمية"، يُعرض رف الكتب الرقمية المضافة مع زر استيراد كتاب جديد (`+ استيراد كتاب ZIP / مجلد`).
2. **استعراض وتصفح الكتاب (Interactive Reader)**:
   - يفتح عارض الكتاب بشريط علوي يحمل زر العودة، عنوان الكتاب (مثلاً: `Miteinander! A1.1 KB+AB`)، وأداة البحث والقفز السريع للصفحة.
   - في المنتصف: عارض صفحات أفقي يحاكي تماماً الصورة المرفقة (الصفحة السابقة، الصفحة الحالية بظلال وبرواز أنيق، الصفحة التالية) مع رقم الصفحة أسفلها.
   - يدعم التمرير بالسحب (Swipe/Drag)، ومفاتيح الأسهم في لوحة المفاتيح، والنقر على الصفحات الجانبية للانتقال الفوري.
3. **قائمة وسائط الصفحة المتزامنة (Media Binding)**:
   - أسفل عارض الصفحات، تُقرأ مصفوفة `media` الخاصة برقم الصفحة المعروضة فقط.
   - لكل مقطع: رقم المقطع واسمه، ونوعه (`Audio` أو `Video`)، وزر التشغيل الأزرق السهمي `▶`.
   - عند النقر، يُفتح المقطع مباشرة في مشغل الوسائط مع الحفاظ على موضع الصفحة لتكرار الاستماع ومتابعة التمارين.
4. **تنسيق وضبط جدول التفاصيل في مستعرض الوسائط**:
   - ضبط أعمدة الجدول: الاسم مع أيقونة النوع، الحجم بخط رقمي دقيق، المدة الزمنية، تاريخ الإضافة، مع أزرار تشغيل وخيارات متناسقة تماماً ومحاذاة صحيحة تمنع التداخل.

## 3. القرارات التقنية وهندسة البيانات (Technical Architecture)

### أ. نموذج بيانات الكتاب (Book & Content Data Schema)
```typescript
interface InteractiveBook {
  id: string;
  title: string;
  author?: string;
  coverImage?: string;
  totalPages: number;
  pages: BookPage[];
  createdAt: string;
}

interface BookPage {
  pageNumber: number;        // e.g. 175
  displayLabel?: string;     // e.g. "7" or "175"
  pageImage: string;         // Blob URL or resolved file path (e.g. pages/530_25460-p-175.jpg)
  media: BookPageMedia[];
}

interface BookPageMedia {
  id: string;
  trackNumber?: string;      // e.g. "2/36"
  title: string;             // e.g. "2/36 – Audio: L7, 6a"
  type: "audio" | "video";
  fileName: string;          // e.g. "L07_06a.mp3"
  resolvedUrl?: string;      // URL to media file in memory/blob/server
}
```

### ب. محرك معالجة الملفات المضغوطة (ZIP & Directory Parser)
- استخدام مكتبة `jszip` أو معالج مجلدات المتصفح (`webkitdirectory` / FileReader) لقراءة ملفات الـ ZIP محلياً في المتصفح.
- استخراج `content.json` وقراءة خريطة الصفحات (`pages`) والوسائط (`media`).
- تخزين صور الصفحات ومقاطع الصوت كـ Object URLs آمنة أو حفظ بيانات الكتاب في IndexedDB لضمان استمراريتها حتى بعد إعادة تحميل الصفحة.

### ج. محرك التخزين المؤقت والأداء (Caching & Lazy Loading)
- تخزين صور الصفحات الحالية والمجاورة (+1 و -1) فقط في ذاكرة العرض لتحقيق تقليب فائق السرعة وخفة في استهلاك الذاكرة.

## 4. مراحل التنفيذ والمهام البرمجية (Implementation Steps)

1. **تثبيت مكتبة التعامل مع ملفات ZIP**:
   - تثبيت `jszip` لتفريغ حزم الكتب الرقمية واستخراج البيانات والوسائط بسلاسة في المتصفح.
2. **إنشاء مكوّن عارض الكتب الرقمية `BookReaderWorkspace.tsx`**:
   - بناء شريط التنقل العلوي مع العنوان والبحث وأرقام الصفحات.
   - بناء عارض التقليب الأفقي الثلاثي (Carousel) التفاعلي المطابق للصورة.
   - بناء قائمة تشغيل الوسائط المرتبطة بكل صفحة مع زر التشغيل `▶`.
3. **توفير كتاب تجريبي تفاعلي مسبق التثبيت (Demo Book)**:
   - إضافة بيانات افتراضية تطابق العينة المرفقة بالصورة (`Miteinander! A1.1 KB+AB`) حتى يتمكن المستخدم من اختبار وتجربة النظام فوراً دون الحاجة لرفع ملفات كبيرة أولاً.
4. **دمج قسم الكتب في `MediaPlayerWorkspace.tsx`**:
   - إضافة شريط التبديل بين `مستعرض الوسائط` و`الكتب الرقمية`.
   - ربط زر تشغيل صوت/فيديو الكتاب باستوديو المشغل الحالي بسلاسة.
5. **تنسيق وضبط جدول التفاصيل في `MediaExplorerView.tsx`**:
   - إعادة وزن نسب أعمدة جدول التفاصيل وتصحيح ترتيب النصوص والأحجام والتواريخ لتفادي أي عشوائية في المظهر.
6. **التحقق والاختبار (Verification)**:
   - فحص الأخطاء عبر `lint_applet` و `compile_applet`.
